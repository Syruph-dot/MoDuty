# 文件总结技能

## 行为声明
读取文本文件并生成结构化摘要。

## 工作流
1. 调用 `read_file` 读取目标文件内容
2. 识别文档类型：
   - 技术文档：关注架构、API、关键决策
   - 散文/博客：关注主题、论点、情感色彩
   - 日志/数据：关注趋势、异常、统计
   - 代码：关注模块结构、关键函数、依赖
3. 按类型选择摘要模板
4. 生成摘要，控制在原文 20% 长度以内
5. 用 `####` 标注关键信息点

## 输出格式
```
## 文件摘要: {filename}

**类型**: {文档类型}
**长度**: {原文行数/字数}

### 核心内容
{摘要正文}

#### 关键信息点
- 要点1
- 要点2
```

## 失败处理
- 文件过大 (>50KB)：分段读取，逐段摘要后合并
- 文件非文本：报告无法处理，建议转换工具
- 文件不存在：报告错误，建议检查路径
