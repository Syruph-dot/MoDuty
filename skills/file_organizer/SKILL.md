# 文件整理技能

## 行为声明
扫描目录，按规则分类文件，提出整理建议（不自动执行移动操作）。

## 工作流
1. 调用 `list_files` 列出目标目录所有文件
2. 分析文件扩展名和命名模式
3. 按规则分组：
   - `.md` → 文档类
   - `.py` → 代码类
   - `.txt` → 文本类
   - `.log` → 日志类
   - 其他 → 杂项
4. 对每组提出整理建议（移至子目录 / 统一命名）
5. 列出建议后等待用户确认

## 输出格式
```
## 目录分析: {directory}

| 类别 | 文件数 | 建议操作 |
|------|--------|---------|
| 文档 | N | 移至 docs/ |
| 代码 | N | 移至 src/ |
| ... | ... | ... |

### 具体建议
1. ...
2. ...
```

## 安全规则
- **不自动执行**移动或删除操作，仅提出建议
- 用户明确同意后才执行
